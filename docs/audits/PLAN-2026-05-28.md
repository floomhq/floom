## 7. Security spot checks (owner: codex-roast)

- Sandbox isolation: trigger a run, `sandbox.commands.run("env | grep -E 'FLOOM|COMPOSIO|E2B'")` returns empty.
- Auth: bare `GET /workers` no secret → 403. Webhook paths reachable. New `/cli-auth/*` reachable.
- XSS: inject `<img src=x onerror=alert(1)>` and `<script>alert(1)</script>` into worker name + description + run inputs. Open every page rendering these. Confirm escaped (React JSX default; only risk = `dangerouslySetInnerHTML` usage).
- Path traversal: `/runs/<id>/bundle/../../etc/passwd` → 4xx, never 200.
- Draft cost cap: hammer `POST /workers/draft-from-prompt` past the cap → 429 + `Retry-After`.
- Rate limit: try `>2000 req/min` from one secret → 429.
