Key Layout Decisions
Rail width (open) 460px (~32% of 1440px) — matches Cursor / GitHub Copilot range
Rail width (collapsed) 48px icon strip — Vercel dashboard pattern. Not hidden, not a FAB.
Collapse pattern Icon strip: Emily avatar + new conversation + runs + approvals (with notification dot)
Resize 6px drag handle on left edge of rail (CSS col-resize cursor, fades in on hover)
PromptInput rounded-3xl border p-2 shadow-xs — exact prompt-kit class. Pill shape.
Message bubbles Assistant: rounded-lg p-2 bg-secondary. User: bg-primary text-primary-foreground.
Agentic cards shadcn border border-radius-lg bg-card. No colored left borders. No gradients.
Emily accent #59AAF8 — avatar, notification dots, streaming indicator only. Nowhere else.
